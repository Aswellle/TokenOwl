## 5. Release Gate

任何以下情况存在时不得发布：

### Blocker

- 构建失败
- 安装失败
- secret 泄漏
- database migration 破坏用户数据
- quota calculation 明显错误
- floating window 无法关闭/移动
- Windows/macOS 主流程 crash

### High Risk

- Provider 某些响应导致 scheduler crash
- stale 数据显示为实时
- reset 倒计时计算错误
- keychain 读取失败导致 app crash
- updater 覆盖失败无法恢复

### Medium

- 非核心 Provider 缺失
- chart minor issue
- visual polish
